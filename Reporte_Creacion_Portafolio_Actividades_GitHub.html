1. Resumen Ejecutivo y Objetivos

El presente informe documenta el desarrollo y publicación de la plataforma web oficial para la consulta, gestión y lectura interactiva de actividades del equipo Los Técnicos en la Universidad Tecnológica de Coahuila.

El objetivo central fue satisfacer la necesidad de que cualquier docente, alumno o evaluador pueda acceder a la página web desde cualquier equipo (Windows, Mac, Linux, Android, iOS) y visualizar y leer directamente los archivos PDF subidos, sin requerir software externo ni iniciar sesión.

2. Paso 1: Arquitectura de Software y Organización de Archivos

El proyecto fue concebido como una Single Page Application (SPA) desacoplada con cero dependencias de servidor runtime, utilizando estándares web abiertos (HTML5, CSS3, JavaScript ES6+, IndexedDB y JSON estático):

Figura 1: Organización estructural del proyecto y desglose de módulos estáticos.

  • index.html: Interfaz gráfica completa, barra de integrantes, métricas en tiempo real, catálogo de tarjetas, modal de creación y contenedor del visor de PDF.
  • css/styles.css: Sistema de diseño responsivo con variables CSS, esquema visual institucional y componentes estilizados.
  • js/db.js: Capa de almacenamiento en IndexedDB y sincronizador con data/actividades.json para visibilidad universal.
  • js/app.js: Lógica de controlador, captura automática de fecha y hora local, selector dinámico de integrantes y visor modal de PDFs.
  • data/actividades.json: Catálogo oficial de actividades del repositorio que garantiza que cualquier usuario en el mundo vea los documentos al ingresar a la URL.
  • assets/: Almacén de archivos PDF oficiales servidos directamente por HTTP/2 en GitHub Pages.

9. Guía de Actualización Continua (Cheat Sheet)

Para añadir nuevas actividades y asegurar que permanezcan visibles universalmente para todos los usuarios en la web:

# 1. Copiar el nuevo PDF en la carpeta assets/
# Ejemplo: assets/Actividad_03.pdf

# 2. Agregar el registro en data/actividades.json con nombre, fecha, integrantes y pdfUrl.

# 3. Publicar en GitHub:
git add .
git commit -m "feat: Agregar Actividad 3 al portafolio"
git push origin main
# En menos de 60 segundos la nueva actividad y su PDF estaran disponibles en linea.
