1. Introducción y Justificación del Sistema

El propósito de este informe es documentar de forma clara y visual cómo se creó el repositorio central en GitHub, cómo se configuró la arquitectura de ramas para el trabajo en equipo y cómo se suben actividades y documentos PDF para que cualquier usuario o docente pueda consultarlos y leerlos directamente en el navegador.

2. Creación y Configuración del Repositorio en GitHub

Se inicializó el repositorio remoto portafolio-actividades-tecnicos bajo la cuenta oficial pyedgar con visibilidad pública para permitir el acceso libre a través de GitHub Pages:

Figura 1: Proceso de creación y parametrización del repositorio en GitHub con comandos de vinculación inicial.

# Comandos de inicialización local y vinculación remota
cd "C:\Users\ed\.gemini\antigravity\scratch\portafolio-actividades"
git init
git add .
git commit -m "feat: Inicializar portafolio de actividades con visor de PDF"
git branch -M main
git remote add origin https://github.com/pyedgar/portafolio-actividades-tecnicos.git
git push -u origin main

3. Configuración y Gestión de Ramas Colaborativas (Git Branches)

Para evitar conflictos de fusión (merge conflicts) y permitir que cada alumno suba sus avances sin interferir en los demás, se creó una rama de trabajo individual para cada integrante del equipo Los Técnicos:

# Crear una rama personal de trabajo y subirla a GitHub:
git checkout -b E_Reyes
git push -u origin E_Reyes

# Cambiar entre ramas existentes:
git checkout main         # Regresa a la rama principal
git checkout E_Reyes      # Cambia a tu rama de trabajo

4. Cómo Subir Actividades: Método 1 (Plataforma Web Interactiva)

La plataforma cuenta con un formulario interactivo accesible mediante el botón «+ Nueva Actividad»:

Figura 3: Flujo de 4 pasos para registrar actividades y visualizar archivos PDF en la plataforma web.

  1. Nombre de Actividad: Identificador claro de la entrega.
  2. Fecha Automática: Se asigna automáticamente con el día y la hora exacta del sistema, con botón de sincronización instantánea.
  3. Descripción: Resumen, instrucciones u objetivos de la actividad.
  4. Grupo: Selección predefinida de Los Técnicos - UTC (Grupos A y B).
  5. Integrantes: Casillas de verificación para marcar a los miembros participantes.
  6. Subir PDF: Zona interactiva Drag & Drop para arrastrar y soltar el archivo .pdf.

5. Cómo Subir Actividades: Método 2 (Control de Versiones en Git)

Para asegurar que una actividad quede almacenada en el repositorio y sea visible para cualquier persona en cualquier equipo mediante GitHub Pages:

Figura 4: Flujo técnico en terminal para publicar actividades en data/actividades.json y sincronizar con Git.

# 1. Copiar el PDF en la carpeta assets/
Copy-Item "Mi_Actividad.pdf" "assets/Actividad_04.pdf"

# 2. Registrar en data/actividades.json la actividad con sus metadatos y la ruta "assets/Actividad_04.pdf"

# 3. Guardar cambios en tu rama y subir a GitHub:
git checkout -b E_Reyes
git add assets/Actividad_04.pdf data/actividades.json
git commit -m "feat: Agregar Actividad 4 y PDF"
git push origin E_Reyes

6. Fusión de Ramas (Merge) y Despliegue en GitHub Pages

Para integrar los aportes de las ramas individuales hacia la rama principal main y activar la actualización en vivo de GitHub Pages:

Figura 5: Diagrama de integración continua desde ramas individuales hacia main y despliegue en GitHub Pages.

# Protocolo de integración segura:
git checkout main
git pull origin main
git merge origin/E_Reyes   # O la rama correspondiente
git push origin main
# GitHub Pages publica automáticamente el nuevo contenido en menos de 60 segundos.

7. Buenas Prácticas y Prevención de Errores

RECOMENDACIONES CLAVE:
  • Siempre ejecutar git pull origin main antes de empezar a trabajar.
  • Nunca trabajar directamente en la rama main; realizar los cambios en ramas de integrantes.
  • Si ocurre un bloqueo por index.lock tras un cierre abrupto, eliminarlo con: Remove-Item ".git\index.lock" -Force.
  • Utilizar el botón «Respaldar» de la web para guardar una copia local en formato JSON con todos los archivos PDF.
